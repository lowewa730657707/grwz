## 二、整体设计：从“答题”改成“调查”

### 1. 双层结构

每份卷宗不再是一道题，而是两阶段：

```
读档案 → 用取证工具校正主谜题 → 解锁“追查”
      → 完成追查 → 校正字显影 + 索引字收入索引柜
      → 九枚校正字 → 终章排序 → 姓名栏 → 结局
      → 九条暗语 → 隐藏终章
      → 九段追查 → 索引柜 → DA-000
```

主谜题负责“读懂档案”，追查负责“动手调查”。两阶段使用**完全不同的交互**，所以每一章都不是“换一个输入框”。

### 2. 十八段互动

- 九个主谜题工具：表盘、楼层剖面、数字键盘、日历、电梯面板、电话键盘、邮编转轮、摩斯译码台、双滑块。
- 九段追查玩法：翻牌、手电、擦渍、显影、监控切换、调频、分拣、灯塔转向、图层对齐。
- 另有两段终局：九枚校正字排序、姓名栏填写。

### 3. 检索台：让答案变成“检索词”

主谜题通过后，答案会被收录进检索台。把答案输入检索台，会翻出：

- 该案的**追查记录**（未完成时可直接跳转）；
- 该案的**索引字**（已完成时）；
- 已恢复暗语的**被删除评论**；
- 跨案馆内词条：404、镜湖、老辑头、槐树十三号、灰雨衣、夜班、白昼档案馆。

这一步是“用答案寻找其他内容”的核心：答案不是终点，而是下一层的钥匙。

### 4. 索引柜与 DA-000

九段追查各给一个索引字，检索台的索引柜会按 DA-001 → DA-009 自动排列。九格全满后解锁 **DA-000《馆内总索引》**：

- 临聘名册（001 / 007 / 013 / 016 / 017）；
- 一句馆训：**你不是第一个临聘员。也不会是最后一个。**
- 第二季 `DA-011 / NIGHT SHIFT` 的预告。

DA-000 是完成度奖励，不强制；九枚校正字与九条暗语才是终章与隐藏终章的门槛。

### 5. 难度曲线

```
第一章 1/5  时刻推算 + 翻牌
第二章 2/5  规则阅读 + 手电搜寻
第三章 2/5  校验位 + 擦渍
第四章 3/5  营业日 + 显影
第五章 3/5  按钮序号 + 监控
第六章 4/5  T9 多击 + 调频
第七章 4/5  邮编校验 + 分拣
第八章 5/5  摩斯 + 灯塔
第九章 5/5  坐标取舍 + 图层
终章   5/5  整合 + 元叙事
```

## 三、逐章主谜题答案

### 序章 · 入职通知

- **谜面**：值班表签名栏要求签下工号；姓名栏留空。
- **答案**：`017`（也受理 `17`、`临聘-017`）。
- **解释**：工牌上写着“临聘-017”，签名栏要的是工号而不是姓名。姓名栏由档案自己填写——这是终章反转的第一次暗示。

---

### 第一章 · DA-001 末班车没有回程

- **答案**：`15:17`
- **关键线索**：总站不计站；站间 3 分钟；停靠 4 站；公告与论坛都强调“从总站数会差一站”。
- **推导**：总站不计 → 第 1 站在发车后 3 分钟；到第 4 站经过 **4 段**：`4 × 3 = 12` 分钟；`15:05 + 12 = 15:17`。
- **工具**：表盘拨到 15:17。
- **暗语**：`雨衣`（灰雨衣 / 灰色雨衣 / raincoat）。
- **暗语字**：白。

---

### 第二章 · DA-002 住户手册缺了第 7 页

- **答案**：`8 层`
- **关键线索**：704 的首位是门牌段号；7 层不设；7 段整体上移一层，与 8 段并层：701—706 与 801—806 均在 8 层。
- **推导**：704 = 7 段 04 号 → 7 段位于 8 层 → **8 层**。
- **工具**：楼层剖面点 `08F`。
- **暗语**：`第七页`（第7页 / 7页 / 七页 / page7）。
- **暗语字**：昼。

---

### 第三章 · DA-003 404 室的快递

- **答案**：`6`
- **推导**：`4 + 0 + 4 + 1 + 7 + 0 = 16`；取个位 → **6**；完整运单号 `LZ-404170-6`。
- **工具**：运单键盘按 6，提交校验。
- **暗语**：`齿痕`（牙印 / 咬痕 / 咬开）。
- **暗语字**：档。

---

### 第四章 · DA-004 只在周二营业的照相馆

- **答案**：`2009-12-15`
- **推导**：1 个营业日 = 1 个周二；拍摄日不计 → 第 1 个营业日 11-03；第 7 个是 **12-15**；等价于 `10-27 + 7 周`。2009-10-27 与 12-15 都是周二。
- **工具**：日历点 12 月 15 日。
- **暗语**：`周二`（星期二 / 礼拜二 / tuesday）。
- **暗语字**：案。

---

### 第五章 · DA-005 电梯监控里的第 13 层

- **答案**：`B1`
- **推导**：面板 1—12 + B1 = **13 个按钮**；显示板只显示按钮序号；第 13 个按钮 = **B1**。
- **工具**：电梯面板按 `B1`。
- **暗语**：`13`（十三 / 13层 / 13号键）。
- **暗语字**：馆。

---

### 第六章 · DA-006 市政热线的第 42 通录音

- **答案**：`HIDDEN`
- **推导**：`42=H`、`43=I`、`31=D`、`31=D`、`32=E`、`62=N` → **HIDDEN**。
- **工具**：电话多击输入 HIDDEN（同字母连写用“断字”或停顿）。
- **暗语**：`影子`（没有影子 / shadow）。
- **暗语字**：没。

---

### 第七章 · DA-007 给失踪者的一封退信

- **答案**：`215176`
- **推导**：`2 + 1 + 5 + 1 + 7 = 16`；校验位取个位 **6**；拼接 `21 5 17 6` → **215176**。
- **工具**：六位转轮拨到 215176。
- **暗语**：`1517`（15.17 / 15:17 / 15.17.03）。
- **暗语字**：有。

---

### 第八章 · DA-008 废弃游乐园的广播

- **答案**：`HERE`
- **推导**：`.... = H`、`.` = E、`.-. = R`、`.` = E → **HERE**。
- **工具**：摩斯译码台依次点 H、E、R、E。
- **暗语**：`地址`（address）。
- **暗语字**：夜。

---

### 第九章 · DA-009 地图上不存在的湖

- **答案**：`1729`
- **推导**：只取“分”，不取“度”：北纬 **17**、东经 **29**；北纬在前 → **1729**（拼接，不是相加）。
- **工具**：两个滑块拨到 17 / 29。
- **暗语**：`眼睛`（眼 / 瞳孔 / eye）。
- **暗语字**：晚。

## 四、九段追查答案与操作

### 追查 01 · 站台翻牌（第一章）

- **谜面**：15:17 之后，站牌背面的翻牌器自己亮了；两个乱码字在等一个旧终点。
- **操作**：
  1. 点“第 4 站”（其余站没有翻牌器）；
  2. 点两块字牌循环字符；
  3. 翻成 **镜湖**；
  4. 点“翻到终点”。
- **答案**：`镜湖`
- **追查记录**：翻牌器停在“镜湖”。现行线路图没有这一站，但 2009 年以前的旧图里，17 路终点确实是镜湖码头。
- **索引字**：**你**

### 追查 02 · 猫眼（第二章）

- **谜面**：704 的猫眼从里面被堵住；8 楼走廊里有三样东西不该同时出现。
- **操作**：拖动滑块移动手电，依次照到并点击：
  - 水表（x≈18%）
  - 七件灰衣服（x≈52%）
  - 704 门牌（x≈82%）
- **答案**：三样全部记录。
- **追查记录**：8 楼有 12 户；水表户名 704；灰衣服七件；门牌全部朝内挂。
- **索引字**：**不**

### 追查 03 · 咖啡渍（第三章）

- **谜面**：咖啡渍不是污点，是盖子；下面还有一层字。
- **操作**：点掉 12 块咖啡渍 → 按“记录显影”。
- **答案**：`B1-404-170`
- **追查记录**：渍下面印着 B1-404-170。不是运单号，是柜号、房间号、秒数。
- **索引字**：**是**

### 追查 04 · 照片显影（第四章）

- **谜面**：最后一张底片没有冲洗；照片里多出一个人。
- **操作**：拖动显影液到 **70% 以上** → 点“多出来的人” → 按“定影”。
- **答案**：标记多出来的人。
- **追查记录**：你身后的人穿灰雨衣、没有影子；右下角写着“第 7 个营业日，别回头”。
- **索引字**：**第**

### 追查 05 · 监控切换（第五章）

- **谜面**：四路监控，只有一路在 15:17:03 拍到过 13。
- **操作**：点 **CAM 04** → 变焦推到 **70% 以上** → 按“定格”。
- **追查记录**：CAM 04 角落写着“13 号键 = B1”；画面里没有人，门缝里有一双鞋。
- **索引字**：**一**

### 追查 06 · 频率调谐（第六章）

- **谜面**：录音第二层在 1517Hz 载波上。
- **操作**：把频率推到 **1517Hz**（±15 内）→ 按“锁定频率”。
- **追查记录**：1517Hz 上有一段摩斯 `-. .. --. .... -`（NIGHT）。第 42 通电话不是求救，是夜班交接。
- **索引字**：**个**

### 追查 07 · 退信分拣（第七章）

- **谜面**：按“注销区”重新分拣，别让 404 落单。
- **操作**：先点信封，再点同号码格口；四封全部归位后自动归档。
  - 2151 → 2151
  - 2152 → 2152
  - 404 → 404
  - 1729 → 1729
- **追查记录**：分拣完多出一个格口 DA-000，里面没有信，只有一张临聘名册。
- **索引字**：**临**

### 追查 08 · 灯塔转向（第八章）

- **谜面**：顶灯不是灯语，是灯塔；雾里有五个字母。
- **操作**：转动光束，依次照亮并点击：
  - N（0°）、I（72°）、G（144°）、H（216°）、T（288°）
- **答案**：`NIGHT`
- **追查记录**：光束拼出 NIGHT。闭园后，灯塔一直朝档案馆的方向转。
- **索引字**：**聘**

### 追查 09 · 图层对齐（第九章）

- **谜面**：旧图与现图之间还差一张透明图层。
- **操作**：拖动 X / Y 滑块，把十字对准湖心：**X=62，Y=44**（±8 内）→ 按“叠合”。
- **追查记录**：叠合后湖心坐标 1729，房间编号 DA-000；图纸背面写着“你不是第一个临聘员”。
- **索引字**：**员**
