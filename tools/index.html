功能介绍

FEATURES

内容只在本地处理

文件、文本与计算结果只在浏览器内存中处理，不上传、不转存、不生成临时下载链接。

无需注册

没有账号体系、次数限制与会员门槛，打开页面即可使用；偏好设置仅保存在你自己的浏览器。

离线可用

依赖库随站点一起分发，页面缓存后断网也能继续打开；适合在无外网的电脑上处理敏感内容。

结果可控

每个工具都提供预览、复制与下载三类出口，生成文件直接落到本地，不经过第三方服务。

使用说明

HOW TO USE
  1. 01

    找到工具

    按左侧分类浏览，或在顶部搜索框输入工具名、关键词与拼音首字母。支持 PDF、二维码、个税、正则、元素周期表等中英文检索。

    在结果区预览、复制或下载；输入框内按 Enter 与 Ctrl / ⌘ + Enter 都能直接执行。运算全程在本机完成，处理完成后可直接关闭页面，不会在服务器留下副本。

关于拾器 ToolBox

一个把常用小工具收进同一页面的本地化工具集。没有账号、没有额度、没有上传队列，能离线就离线，能本地就本地。

01功能介绍

拾器把日常遇到的小任务拆成独立工具，按使用场景分为图片、设计、音视频、文件、二维码、财税、法律、换算、生活、教育、文本、开发、系统与益智十四类。每个工具只做一件事，参数说明、使用提示与输出说明都整理在工具页下方，不需要阅读额外教程。

  • 统一在本机运算：文件读取、转码、压缩、加密全部借助浏览器 API 与本地依赖库完成。
  • 工具页采用左右分栏：左侧调参数、右侧看预览，两栏各自吸顶，避免上下滚动来回对照。
  • 窄屏使用「参数设置 / 结果预览」两个标签切换，结果刷新后标签上会出现提示点。
  • 输出形式固定为预览、复制、下载三类，减少在不同工具之间来回切换。
  • 对暂未开放的工具明确标注「即将上线」，并推荐同类可用工具。

02使用说明

  1. 浏览或搜索。从左侧分类进入，或使用顶部搜索框。搜索支持中文名、功能描述、英文关键词与拼音首字母。
  2. 填写参数。字段说明会解释取值范围；输入框右侧的 × 可一键清空，部分字段提供常用值快捷按钮；文件类参数支持点击选择与拖拽放入。
  3. 查看结果。右侧结果区按类型展示文本、表格、图片或文件，并提供复制与下载按钮；状态条会显示最近一次刷新时间。
  4. 键盘操作。输入框内按 Enter 执行，任何位置按 Ctrl / ⌘ + Enter 也能执行；Ctrl / ⌘ + K 聚焦搜索，Esc 返回列表。
  5. 保存偏好。收藏与深浅色主题保存在浏览器 localStorage 中，清除站点数据后会一并重置。

03隐私与数据

本站不接入统计脚本、广告联盟或第三方登录，也不设置追踪 Cookie。你选择或输入的内容不会离开设备：读取、处理与导出都在当前页面的 JavaScript 运行时内完成，页面关闭后内存即释放。

浏览器本地只会保存三类数据：收藏的工具名、深浅色主题偏好、最近使用记录。它们仅用于改善下次打开时的体验，不包含任何输入内容。

少数工具需要联网并标注「需联网」：中文翻译与多语言翻译调用公共翻译接口，当前 IP 查询与邮箱 MX 检测访问公共查询服务，实时汇率换算、天气查询读取免费开放接口，英文单词释义调用 Datamuse 与 free Dictionary API，语音识别使用浏览器内置服务。请勿向这些工具提交敏感内容。

05技术说明

站点为纯静态页面，不依赖后端接口。文件处理使用 Canvas、Web Audio、Web Crypto、WebAssembly 与以下本地依赖完成，全部随站点分发：

  • qrcode.js / jsQR / JsBarcode — 二维码与条码
  • pdf-lib / PDF.js / jsPDF — PDF 读写与生成
  • JSZip — 压缩包读写
  • SheetJS — 表格解析与导出
  • lunar.js / pinyin-pro — 农历与拼音
  • heic2any / lame.js / omggif — 格式转换
  • marked.js — Markdown 渲染
